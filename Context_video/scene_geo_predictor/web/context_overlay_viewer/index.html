A · OracleGT 状态 + GT 几何理想输入下的 PyBullet 参考轨迹

Estimated geometry从 context 估计的碰撞盒线框估计障碍物的位置、尺寸、朝向
GT geometry · eval only真值碰撞几何线框与紫色线框对比；仅供评测展示
