V-JEPA 2 视频 Shape 分析

输入视频：/data/gaoya/AAA_test_video/Output_try0526/PDI-Bench/output/GT/Biological_Motion/bear.mp4

采样帧数：64 裁剪尺寸：384 最终 token 数：18432 隐藏维：1408

这个示例对应 V-JEPA 2 的 ViT-g/16 384 版本。输入视频先被标准化为 64 帧、384x384 的张量，再通过 3D patch embedding 压成 18432 个时空 token，每个 token 的维度是 1408，随后 40 层 Transformer 在不改变 token 数的前提下完成特征建模。

视频概况

原视频尺寸 854x480，共 82 帧，FPS 为 24.0。

当前示例从 82 帧里等间隔采样 64 帧，因此没有补帧；只是轻微跳帧压缩时间轴。

关键理解

[1, 3, 64, 384, 384] 进入模型后，经 3D patch embedding 变成 [1, 18432, 1408]。

原因是时间维用 tubelet_size=2 压成 64 / 2 = 32 个时间块，空间维用 patch_size=16 压成 384 / 16 = 24，所以 token 总数为 32 x 24 x 24 = 18432。

后续 40 层 ViT block 不再改变 token 数，主要是在 18432 个时空 token 上做特征混合，最后输出每个 token 的 1408 维表示。
