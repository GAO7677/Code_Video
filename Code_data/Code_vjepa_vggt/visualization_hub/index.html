Visualization Hub

这个入口页把对象级条件提取相关的可视化服务串成一条固定链路。它本身只提供导航，不替代下游服务；点击链接前，需要对应服务已经启动。

context_video -> 对象先验 -> query points -> tracks -> geometry -> object tokens / fused context
