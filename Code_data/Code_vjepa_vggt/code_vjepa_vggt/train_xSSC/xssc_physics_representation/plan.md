# xSSC 物理属性与物体动力学表征实验计划

## 1. 研究目标

本实验不要求 xSSC 直接回归质量、摩擦系数或恢复系数。核心目标是验证：在严格控制其他变量后，物理参数干预是否会在 xSSC 中留下稳定、可重复、具有物体归因能力、且与真实动力学过程时间对齐的表征变化。

需要逐级区分以下结论：

1. 参数干预敏感：参数变化会引起 xSSC 表征变化。
2. 参数响应结构化：不同参数类型、方向和幅度形成可区分的响应模式。
3. 物体级归因：多物体交互中，响应能绑定到被干预物体，并表现出合理的跨物体传播。
4. 动力学一致：从 xSSC 提取的动态代理与轨迹、速度、光流和接触事件一致。
5. 物理相关而非伪相关：上述现象不能由外观、相机、普通位移或 slot 身份漂移单独解释。

除非额外通过参数解码和轨迹控制实验，否则结论表述为“xSSC 隐式编码与物理属性及其动力学后果相关的信息”，不表述为“xSSC 恢复了模拟器真实参数”。

## 2. 总体原则

- 冻结 xSSC；主实验研究已有表征，不通过微调让模型学习测试集参数。
- 反事实组内一次只改变一个变量。
- 独立统计单位是基础仿真 seed，不是帧、视频 pair 或外观重渲染版本。
- 同一 seed 的全部参数变体、外观版本和视角版本必须位于同一数据划分。
- 不预设简单时间差分就是正确动力学表征；动态代理函数本身需要经过候选比较和独立验证。
- GT mask/bbox 主要用于匿名 slot 的物体身份绑定和质量评估，不能把逐帧 GT 状态输入 xSSC。
- 第一帧视觉输入和 bbox 条件在反事实组内保持一致，避免初始化条件泄漏参数身份。
- 所有原始 slot、attention、decoder 特征、GT 状态、RAFT 和中间指标均落盘，最终分数可重新计算。

## 3. 实验模块及目的

### E0：数据与 Slot 质量审计

目的：确认后续特征变化不是 slot 合并、漏检、身份切换或预处理差异造成的。

输出：每个 case/物体的 slot recall、mask IoU、identity switch、重复 slot、可见性和失败原因；同时生成质量分层，不静默删除失败样本。

### E1：单参数反事实敏感性

目的：验证只改变质量、摩擦或恢复系数时，raw slot、attention 和 decoder 特征是否产生稳定变化。

输出：按参数类型、目标物体和档位组织的组内响应，不在此阶段强制做参数回归。

### E2：剂量与参数类型特异性

目的：区分“模型只发现视频不同”和“模型对物理干预具有结构化响应”。

输出：参数变化幅度与特征响应的趋势，以及不同参数类别响应模式的组内一致性和组间可分性。

### E3：动力学代理搜索

目的：从 xSSC 表征中寻找能够稳定刻画物体运动变化的动态量，而不是预设单一差分公式。

候选来源：raw slot 的多尺度时间算子、attention/centroid 算子、transition/decoder 内部特征、频域算子，以及由 GT 轨迹或 RAFT 监督的低容量映射。

输出：候选动态代理排行榜、跨 seed/数据源泛化结果、失效案例和最终冻结的 D_xSSC 定义。训练型代理必须按 seed 划分训练和验证，RAFT/GT 只作为监督或验证信号。

### E4：动力学事件时间对齐

目的：判断 D_xSSC 的响应是否出现在正确的物理阶段，而不是由外观变化或 slot 漂移提前/滞后触发。

输出：碰撞前、接触、反弹/滑动、碰撞后阶段的响应曲线，并与位置、速度、角速度、RAFT 和接触事件对齐。

### E5：多物体归因与传播

目的：验证只改变物体 A 的参数时，xSSC 是否能定位 A，并在交互后表现出向物体 B 的合理影响传播。

输出：目标物体响应、非目标物体响应、传播时延、参数/位置互换对照，以及 ball/block 分角色曲线。

### E6：外观、相机与普通轨迹对照

目的：排除纹理、光照、视角、位置变化和简单光流足以解释结果的可能性。

输出：物理干预效应与外观干预效应的对比；xSSC 与 DINOv3、RAFT、mask centroid、GT 运动学等基线的比较。

### E7：可选的参数探针

目的：作为强化证据，检查冻结表征中物理相关信息是否可以被低容量模型读出；这不是支持主结论的必要条件。

输出：按 seed 划分的线性/ridge probe 结果，以及 xSSC 相对纯轨迹输入的增量信息。高容量 MLP 只作为诊断上限。

## 4. 分阶段执行

### Phase 0：现有资产核查（已完成）

- 找到 8 个 `ball_block` 单参数控制视频：恢复系数 4 档、摩擦 3 档、质量 3 档，共用 `e=0.7, mu=0.5, mass=1.0` 基准。
- 找到 24 个同物理过程的外观重渲染，可用于外观伪相关对照。
- 找到当前 DINOv3 MOVi-C step-044000 的 object-aligned slot、decoder-static/dynamic 和可视化缓存。
- 找到已有 90 个训练视频上的 xSSC/RAFT 动态代理筛选结果；当前简单 L2 类算子相关性较高，但 decoder-static 与 decoder-dynamic 表现接近，不能据此声称原生通道已完成静态/动态解耦。
- 仿真脚本能够导出位置、姿态、线速度和角速度，但现有 8 个 preview JSON 没有逐帧状态；脚本尚未导出接触事件、冲量、instance mask 和深度。

结论：现有资产足够进行小规模复核和代码开发，不足以支持正式统计结论。

### Phase 1：现有 8+24 视频的轻量复核

- 统一预处理、帧索引和 slot 身份绑定。
- 汇总 raw slot、attention、decoder 分区和已有动态代理。
- 比较物理参数变化与外观变化的效应量。
- 输出 pilot 报告，并确定新数据必须解决的质量问题。

进入下一阶段的门槛：结果文件可追溯；slot 失败单独报告；同轨迹外观变化不会系统性淹没物理变化。

### Phase 2：扩展仿真与 GT 导出

- 在独立输出目录中扩展生成器，不覆盖现有数据。
- 支持多 seed、参数档位、被干预物体、初始条件和外观/相机重渲染。
- 导出逐帧位姿、速度、角速度、接触、冲量、instance mask、可见性及相机参数。
- 先生成小规模 smoke 数据，核对组内除目标参数外完全一致。

进入下一阶段的门槛：反事实一致性检查通过；GT 与视频逐帧严格对齐；同 seed 分组信息完整。

### Phase 3：动态代理候选开发与选择

- 解析型候选：相邻差、相对首帧、多时间尺度、局部窗口、频域和 attention 运动。
- 内部候选：transition 更新量、decoder-static、decoder-dynamic 及其时序算子。
- 学习型候选：以 GT 轨迹/速度/RAFT 为目标的线性、低秩或小型时序映射。
- 使用开发 seed 选择方法，在独立验证 seed 冻结最终公式。

进入下一阶段的门槛：最终代理跨 seed 稳定、优于简单失败基线，并对外观变化具有可接受鲁棒性。

### Phase 4：正式反事实、归因和事件实验

- 完成 E1-E6。
- 所有结果同时按 slot 质量分层和全样本汇报。
- 以 seed 为单位计算置信区间和置换检验。

### Phase 5：可选参数探针与论文结论

- 仅在前述主实验成立后运行 E7。
- 根据证据强度区分“运动敏感”“物体级动力学编码”“物理属性相关表征”三个结论层级。
- 汇总支持结论、反例、非可辨识情形和方法限制。

## 5. 数据规模策略

- Pilot：先使用现有 8 个物理视频和 24 个外观版本开发分析流程。
- Smoke：扩展生成器后先生成少量 seed，核对 GT、slot 和事件对齐。
- 正式规模：先运行约 30 个独立 seed 估计 seed 间方差，再根据目标最小效应和功效分析确定最终 seed 数；不以帧数虚增样本量。

## 6. 结果组织

- 轻量代码与配置：`train_xSSC/xssc_physics_representation/`
- 大型缓存和结果：`/data/gaoya/agent-data/outputs/xssc_physics_representation/`

每个正式 run 必须保存：配置快照、代码版本/哈希、模型权重路径、数据 manifest、随机 seed、预处理参数、逐 case 原始特征、质量指标、聚合表格和可视化入口。

## 7. 正式执行前待确认

1. 主模型与比较模型：以哪个 xSSC checkpoint 作为主实验；是否同时比较官方 DINOv2 xSSC。
2. 仿真范围：只做 ball-block，还是第一版同时加入单物体反弹/滑动任务。
3. 被干预参数：首轮是否限定质量、摩擦、恢复系数；参数作用于 ball、block 还是分别作用。
4. xSSC 条件：GT 仅用于 slot 身份绑定，xSSC 仍只输入第 0 帧 bbox，是否确认。
5. 动态代理：是否允许训练低容量监督映射；若允许，GT 轨迹与 RAFT 都作为候选监督，但独立报告。
6. 资源：允许使用的 GPU 编号和并发策略；GPU 4 按 workspace 规则禁止使用。
7. 规模：确认先完成 Phase 1，再生成小规模 smoke，审阅后才启动 30-seed pilot。
