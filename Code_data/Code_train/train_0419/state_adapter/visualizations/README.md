# State Adapter Visualizations

Files:

- `visualize_oracle_state_adapter_sample.py`
  Build a local HTML report for one oracle-state adapter training sample.

- `visualize_oracle_state_adapter_arch.py`
  Render an architecture page for how the oracle-state adapter is inserted into Wan DiT.

- `visualize_stage1_subsets.py`
  Build a local HTML portal for sampled Stage-1A / Stage-1B subset windows, including RGB overlays and per-object state plots.

- `visualize_motion_complexity_buckets.py`
  Build a local HTML portal that groups oracle-state windows by motion-complexity buckets.

- `visualize_window_interaction_buckets.py`
  Build a local HTML portal that groups oracle-state windows by object count and future collision buckets.
