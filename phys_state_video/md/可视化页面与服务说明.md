# 可视化页面与服务说明

## 页面形式

- 静态页面：`report.json` + `index.html`
- 服务方式：`python3 -m http.server`

## 主入口页

- 脚本：`/home/gaoya/Code_Video/phys_state_video/scripts/generate_method_overview_page.py`
- 输出目录：`/data/gaoya/AAA_test_video/Dataset_physV/phys_state_0601/runs_v1/method_overview_v1`
- 页面：`index.html`
- 端口：`18834`

### 接入逻辑

- 读取各方法目录下的 `report.json`
- 生成 `index.html`
- 生成 `compare_best/index.html`
- 在输出目录启动静态服务

### 代码位置

- `generate_method_overview_page.py`
- `start_server(...)`
- `build_index_html(...)`
- `build_compare_html(...)`

### 启动命令

```bash
python3 /home/gaoya/Code_Video/phys_state_video/scripts/generate_method_overview_page.py --clean --port 18834
```

## 训练中 ckpt 时间线页

- 脚本：`/home/gaoya/Code_Video/phys_state_video/scripts/watch_adapter_cases.py`

### 接入逻辑

- 扫描 `checkpoint-dir`
- 调用 `export_trained_cases.py`
- 生成 `output-root/cases/<ckpt_name>/index.html`
- 生成 `output-root/index.html`
- 在 `output-root` 启动静态服务

### 代码位置

- `watch_adapter_cases.py`
- `export_trained_cases.py`

### 启动命令

```bash
/data/gaoya/miniconda3/envs/vjepa2/bin/python \
  /home/gaoya/Code_Video/phys_state_video/scripts/watch_adapter_cases.py \
  --env-py /data/gaoya/miniconda3/envs/vjepa2/bin/python \
  --project-root /home/gaoya/Code_Video/phys_state_video \
  --episode-root /data/gaoya/AAA_test_video/Dataset_physV/phys_state_0601/episodes_v1/industrial_s1_scale2_256x144_s8_f16_n6 \
  --predictor-checkpoint /data/gaoya/AAA_test_video/Dataset_physV/phys_state_0601/runs_v1/industrial_s1_scale2_latent_v1/checkpoints/predictor_best.pt \
  --checkpoint-dir /data/gaoya/AAA_test_video/Dataset_physV/phys_state_0601/runs_v1/industrial_s1_scale2_latent_v1/checkpoints \
  --output-root /data/gaoya/AAA_test_video/Dataset_physV/phys_state_0601/runs_v1/industrial_s1_scale2_latent_v1/viz/training_ckpts \
  --port 18833 \
  --poll-seconds 180 \
  --max-cases 12 \
  --fps 6 \
  --device cuda
```
